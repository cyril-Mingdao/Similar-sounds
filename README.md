# 🎧 聽韓語．拼台羅（Similar sounds）

教師在大螢幕投影，即時組合韓文的子音、母音、收音並播放韓語音；學生聽音後練習拼出相同組合的**台語羅馬字**，教師再依序公布「聲母 → 韻母 → 聲調 → 台語羅馬字」，並可播放台語音。

## 頁面

| 檔案 | 用途 |
|---|---|
| `index.html` | 投影頁（上課用） |
| `review.html` | 聲調審聽頁（教師審聽、修正拼音與聲調） |

## 操作

- 左側點子音、母音（收音可不選）→ 自動播放韓語音
- 點「聲母」「韻母」「聲調」「台語羅馬字」卡片可個別公布；公布後點台語羅馬字播放台語音
- 公布後點「聲母」「韻母」卡，播放詹宗龍老師自行錄製的聲母、韻母音檔（與〈羅馬字拼音互動遊戲〉同一批，`audio_spell/`；ung 等沒有自錄音檔的不能點）
- 簡報筆 ▶：聲母 → 韻母 → 聲調 → 答案 → 播台語音 → 隨機下一題；◀ 倒退
- 隨機出題採洗牌制：題庫每題各出一次，全部輪過才重新洗牌
- 快捷鍵：空白 播放｜S 慢速｜Enter 依序公布｜A 全部公布｜R 隨機｜T 倒數｜Esc 清空

## 題庫

只收韓語與台語羅馬字**近似度 100%** 及教師審聽確認的音節（共 24 個），其餘組合顯示「無近似音」。

## 素材來源

- 韓語音檔：Microsoft Edge 語音合成（ko-KR-SunHiNeural）
- 台語音檔（`audio_tw/`）：
  - 16 個取自教育部《[臺灣台語常用詞辭典](https://sutian.moe.edu.tw/)》同音讀單字詞條的音檔：暗 àm、按 àn、甕 àng、伊 i、飲 ím、引 ín、約 iok、一 it、塭 ùn、熨 ut、覕 bih、嗄 sà、產 sán、送 sàng、四 sì、審 sím。著作權屬教育部，依[創用CC 姓名標示－禁止改作 3.0 臺灣](https://creativecommons.org/licenses/by-nd/3.0/tw/)授權條款以原檔使用，未經剪輯或改作。
  - 其餘 8 個（â、uh、ùng、bā、lah、nih、sám、sín）辭典無同音讀單字詞條，由陽明交大台語 TTS（男聲、台北腔；v19 起由女聲改男聲）產生。
- 台語羅馬字依教育部《臺灣台語羅馬字拼音方案》；聲調依音檔實際音高（Praat 基頻分析）判定並經教師審聽
